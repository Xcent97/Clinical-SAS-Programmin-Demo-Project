Clinical SAS Programming Demo Project - Creation of SDTM Domains(AE, DM, EX, LB, SUPPDM, XP) and ADaM Datasets(ADSL, ADAE) using Dummy Datasets of Clinical Trials named as - "A PHASE IIB, DOUBLE-BLIND, MULTI-CENTER, PLACEBO CONTROLLED, PARALLEL GROUP, RANDOMIZED CLINICAL TRIAL OF ANALGEZIA HCL FOR THE TREATMENT OF CHRONIC PAIN".



**NOTE: This demo project is to showcase hands-on experience with basic clinical SAS programming, and it does not represent any real-world industry project. The demo project was done with the help of datasets provided by my training institution "SAS India" and the SDTM and ADaM Metadata excel sheets were provided to us to understand the variable mapping and derivations.**



Folders are needed to be uploaded or loaded on SAS Tools (i.e SAS Studio or SAS Enterprise Guide) and proper folder path should be used in order to get the results correctly.



Folder contents: Raw\_Data - Contains subject demographics, drug dosing, adverse events, lab data and pain scores.



Ideal Folder Structure would be like:

SAS\_Project --> Raw\_Data, ADaM, SDTM, Formats



ADaM Folder can be used to store final ADaM Datasets and similarly SDTM folder can be used to store SDTM Domains. Formats folder can be used to store custom formats needed for this program.



The project code is also provided in a text file ('SAS\_Clinical\_Trial\_Project.txt') for easy copying and pasting.
